# AI Text Detector

Detects whether an essay was written by a person or generated by an AI model.
Model: TF-IDF (words and word pairs) + linear SVM, trained on the DAIGT V2 Train Dataset.
Test set (4,000 essays): accuracy 0.9932, F1 0.9932, ROC-AUC 0.9997.

Dataset: https://www.kaggle.com/datasets/thedrcat/daigt-v2-train-dataset

## Project structure

```
api/predict.py     prediction function (runs on Vercel, pure Python, no scikit-learn)
api/model.json     exported model weights (made from the .pkl files)
public/index.html  the web page
public/results/    charts shown on the "Model performance" tab
vercel.json        tells Vercel to include model.json with the function
dev_server.py      local test server (no Vercel needed)
export_model.py    converts svm_model.pkl + tfidf_vectorizer.pkl into api/model.json
```

## Run locally

```
python dev_server.py
```
Open http://localhost:3000

## Deploy on Vercel

1. Put this folder in a GitHub repository. The folder contents must be at the repository root,
   so that `api/` and `public/` are visible on the repository's first page.
2. Sign in at vercel.com with your GitHub account.
3. Click **Add New > Project**, choose the repository, leave Framework Preset as **Other**, click **Deploy**.
4. Vercel gives you a public link. Every `git push` redeploys automatically.

If the repository has other files and this app is in a sub-folder, set **Root Directory** to that
sub-folder in the Vercel project settings.

## If you retrain the model

1. Save the new `svm_model.pkl` and `tfidf_vectorizer.pkl` in this folder.
2. Run `python export_model.py` (needs `pip install scikit-learn joblib`).
3. Commit the new `api/model.json` and push.

## Notes

- The first request after a quiet period can take a few seconds while the function starts.
- Text typed into the page is sent to the `/api/predict` function to get the result. It is not stored.
- The result is a probability estimate, not proof of authorship. The model can be less accurate on text
  from other sources or topics than the dataset it was trained on.
